# Wanger Image

打开用户指定的文章，从正文逐个定位占位符。识别用户给定的格式、素材和保存位置。下文的脚本、参考和资产路径均相对于本 Skill 所在目录。

| 读者想看什么 | 取材和制作 |
| --- | --- |
| 官方文档、产品界面、发布数据 | 打开对应版本的原始页面，截取可读区域。对照图里将官方原文与自己的测量分别标明。 |
| 代码运行结果、点击后的状态 | 运行指定 Case，核对输入、版本和真实输出；捕获稳定状态，保留原始画面。多步操作可以把真实帧做成 GIF，最后一帧与输出核对。 |
| 看清结构、对照方案或查数字 | 用手绘静态图。按 [版式与人物参考](references/layouts.md) 选一张参考，使用可用的图像生成工具实际传图；相对于本 Skill 根目录解析表内的 `assets/…`。 |
| 看清循环、并发或事件发生的先后 | 用手绘机制 GIF。让整图常驻，用颜色追踪同一个对象；目标收到数据后再改变状态。 |

**制作手绘图。** 用当前占位符提取标题、短标签、箭头和要表达的结论。使用暖白纸底、粗黑中文标题、蓝色流程、橙色重点、绿色完成。默认用所选版式里的署名讲解员，人物附近保留「©沉默王二」；若用户给了人物参考，按其选择，要求无人物时省略人物与署名。只把与这张图有关的词和参考传给图像工具。核对文字、人物、手臂、署名、箭头方向与遮挡。

**制作 GIF。** 查看主图后按真实像素坐标编排动画。在 macOS 上可用随附的 Swift/AppKit 与 FFmpeg 渲染器；命令和配置见[动画场景格式](references/scene-format.md)。真实 Case 动图直接使用实录帧。检查起点、变化瞬间、最终状态与循环接缝，缩到手机阅读宽度核对文字。用 `python3 scripts/verify_gif.py 图.gif` 完整解码验收。如缺少可用的生成工具、页面或实测结果，保留受影响的占位符，继续处理已有素材。

**回填文章。** 只要预览时交付本地图片。要求替换时，优先服从用户指定的本地目录、图床和既有文章约定；无其他要求时把成品放到文章旁的 `images/`，使用相对链接。仅在用户选择远端存储时上传到其配置的目的地，可按 [OSS 说明](references/oss.md) 操作。先核对素材能够打开，GIF 经 CDN 回读后也要确认类型、字节与原文件一致。把每个成功的占位符原位替换为一条带简短替代文字的 Markdown 图片引用。保留代码样例和其余正文；更新前重新读取文章，避免覆盖并行编辑。

本地已有成品时，可用 `scripts/render_article.py` 将占位符到素材的 JSON 清单渲染为 Markdown，输出到标准输出。清单的键是完整占位符行，值含 `file`（相对文章的文件名）和 `alt`。适用于正文顶格独占一行、每个键只出现一次的占位符；含行内占位符、嵌套引用或列表时按上下文精确编辑。遇到重复项先定位，不按标题模糊替换。
