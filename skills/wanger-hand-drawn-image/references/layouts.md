# Style and Character Patterns

## 人物参考来源与优先级

1. 用户在当前请求中明确提供或指定的人物参考。
2. 当前选中的版式参考中，带 `©️沉默王二` 的外置讲解员。
3. “额外认可参考图”中更适合当前主题、构图或动作的人物。

九张版式路由图和额外认可参考图都包含用户认可的外置二哥形象。默认由当前版式图同时承担人物参考；只有额外参考中的人物姿态明显更合适时，才增加一张只控制人物。调用 `imagegen` 时必须实际传入选中的图片，不要只根据文字配方凭空生成人物。

Maker / Checker、页签机灵和卡片内部人物只表达流程或功能语义，不参与外置二哥身份生成。若一张图同时包含多个角色，以带 `©️沉默王二` 的外置讲解员为人物来源。

用户后续明确表示“这个小人形象很好”或“这张图非常好”并要求加入参考池时，将原图加入 `assets/`，并在本节登记文件名、构图特点和人物姿态；未获明确认可的临时生成图不自动进入参考池。

## 认可小人的共同特征

以下内容只用于审核生成结果是否明显跑偏，不能替代图片参考，也不能覆盖用户当前明确指定的人物图：

- 气质：年轻、亲切、聪明的成年技术讲解员；不是商务肖像或幼态娃娃。
- 常见外形：侧分蓬松深棕短发、黑框矩形或圆角矩形眼镜、清爽偏窄脸、自然克制的眼睛和轻微微笑；具体脸部以当前认可参考图为准。
- 常见服装：黄色纯色或细竖纹衬衫、深色领带、深色长裤；具体服装以当前认可参考图为准。
- 画法：干净 2D 手绘漫画线稿、哑光扁平上色、弱高光和少量纸张铅笔纹理；具体笔触以当前认可参考图为准。
- 构图：默认胸像或半身；只有主题需要时才画全身。全身约 6-7 头身，禁止超长腿。
- 签名：人物附近放小字 `©️沉默王二`。
- 硬性排除：除非用户当前明确认可的参考图本身如此，否则禁止漂成真人皮肤、3D 公仔、偶像日漫海报、强赛璐璐或与认可样本明显无关的第三方角色。

## 人物与道具硬约束

生成含人物、道具或内部角色的图时使用；Quality Gate 复用本节，不另做重复检查。

- 一张图只使用一个主要动作和最多一个主要道具。动作、视线或道具必须与最近的技术节点直接相关，让人物参与讲解、检查、比较、调节或验证当前内容；禁止无内容关联的独立摆拍。不能拿长教鞭。
- 清单板、白板、平板和电脑屏幕必须先确定朝向对象，并遵守唯一可见面；禁止透明板、双面同时可读、镜像穿透文字和手掌穿板。
- 板面朝读者、内容可读时，人物只能扶住边缘、摊手展示或从板外侧指示，不能在读者可见正面书写；人物正在书写时，板面必须朝人物或呈合理侧角，读者不可见的板面内容不能承载标题、关键词或结论。
- 手、笔和手臂必须始终位于人物可触达的物理一侧，不能穿过板面、绕到相反面或悬空跨越板体。无法同时满足可读性和动作透视时，删除人物手持板，改为与画布中已有卡片、节点或箭头互动。
- 所有可见肢体和机械部件必须数量正确、连接自然。生成后必须从左肩和右肩分别沿上臂、肘、前臂、手腕追踪到手，最多两条完整上肢、两只手；禁止多手、多臂、无来源手掌、重复手指、畸形或粘连。
- 一只手持道具、另一只手做指示时，道具上不得再出现独立的按键手、扶持手或第三只手；双手共同持有或操作道具时，禁止再添加任何指示手势。动作超过两只手能自然完成时，简化为单手道具或无道具手势。

## 内容感知摆位

先完成主体，再找最大连续留白，不固定左下：

| 主内容分布 | 人物优先位置 |
| --- | --- |
| 左侧或中央密集，右侧有留白 | 右下或右侧 |
| 右侧密集，左下有留白 | 左下 |
| 横向流程终点占右侧 | 终点外侧或左下 |
| 中央三层架构 | 输入输出较少的一侧 |
| 高密度分析板 | 冲突最小的下角 |

不设置固定人物面积占比或统一上限。人物大小根据画布比例、连续留白、信息密度、全身或半身状态以及互动任务动态决定；人物不得压住标题、关键数字、箭头、结论、图例或内部功能角色，也不得大到抢走主体信息。

人物放入后若其头顶或外侧留下大块无意义空白，优先把主体卡片、层级或流程区域向该空白延展，形成内容包裹人物的布局；不要通过放大人物来填空，也不要保留从标题到底部贯通的空白竖带。

## 页签机灵与内部角色

- 页签机灵用于卡片和节点：竖向圆角纸页一体机身、右上折角页签、深蓝窄条显示窗、短分节机械臂、小滚轮或短支脚。
- 配色使用浅米白机身、黑色手绘轮廓、蓝 / 橙 / 绿功能色；可搭配核验镜、记忆匣、书签或共享文稿。
- 禁止独立圆脑袋、白色软团身体、无服装圆头萌娃和第三方吉祥物轮廓。
- 第 7 张保留页签机灵；第 9 张保留 Maker / Checker 卡片内部的人物插画。它们是版式语义，不得被复刻成外置二哥。

## 九张版式路由

九张版式路由图都包含认可的外置二哥，既是版式来源，也是默认人物来源。选择最匹配的一张，不要同时混用多张；人物大小不要机械照搬，但脸部、发型、眼镜、服装和画法应参考所选图片：

| 排版类别 | 参考资产 | 适用版式 |
| --- | --- | --- |
| `checklist-card` | `assets/itwanger-interview-grid-with-presenter-reference.png` | 三列问题、面试题、分类清单；参考人物融入卡片结构的位置和互动，大小按当前画面决定 |
| `data-board` | `assets/itwanger-analysis-board-reference.png` | 原始输入、证据对比、分类结果、风险结论 |
| `skill-card` | `assets/itwanger-dimension-map-reference.png` | 事实源 + 4-6 张维度卡 |
| `swimlane` | `assets/itwanger-human-check-swimlane-reference.png` | 上层执行、下层人工检查、红色回退 |
| `three-layer` | `assets/itwanger-layered-architecture-reference.png` | 中央三层架构、侧边输入输出、核心便签 |
| `checklist-card` | `assets/itwanger-playbook-cards-reference.png` | 三列纠偏处置卡、成本递进、底部结论 |
| `skill-card` | `assets/itwanger-skill-card-reference.png` | 左侧目录、三张能力卡、页签机灵 |
| `three-layer` | `assets/itwanger-skill-layering-reference.png` | 三层目录、覆盖优先级、加载流程 |
| `whiteboard` | `assets/itwanger-whiteboard-infographic-reference.png` | Maker / Checker、条件判断、通过与回退闭环 |

补充选择：

- `whiteboard` 无专用参考覆盖的普通流程、状态机、对比或演进图，借用第 9 张的手绘语言，但重新按主题布局。
- 额外认可参考图更贴近当前结构时，可替代对应主版式参考，但仍使用最接近的 排版类别 名称。
- 主版式已经合适时，额外认可参考图最多再选一张且只控制人物，不混入第二套布局。
- `skill-card` 的能力卡与维度图只能二选一，不叠加两张参考。
- `three-layer` 的架构分层与目录覆盖只能二选一。
- `checklist-card` 的面试题网格与纠偏处置卡只能二选一。
- `data-board` 中的不确定信息必须标注“示意”“可能”或“待验证”，不能把推测画成事实。
